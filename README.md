## درباره پروژه

**ربات اسکای‌روم** یک برنامه دسکتاپ است که به جای شما وارد کلاس‌های آنلاین اسکای‌روم می‌شود. کافی است برنامه هفتگی کلاس‌ها را یک‌بار وارد کنید — ربات بقیه کارها را انجام می‌دهد: در زمان مقرر با مرورگر ناشناس وارد می‌شود، نام شما را ثبت می‌کند، پیام حضور را می‌فرستد، و اگر کلاس طولانی شد، خودکار در زمان پایان خارج می‌شود.

حتی می‌توانید لپ‌تاپ خود را به خواب بفرستید — ربات قبل از شروع کلاس بعدی آن را بیدار می‌کند.

---

## دو نسخه

از این پس، هر نسخه در **دو حالت** منتشر می‌شود:

**نسخهٔ پایه (base)** — ربات کلاسیک. ورود خودکار، پایش اتصال، خواب و بیدارباش. یک فایل اجرایی سبک.

**نسخهٔ کامل (full)** — همان قابلیت‌های پایه، به‌علاوهٔ **شنوندهٔ زندهٔ Jarvis**: صدای کلاس را می‌شنود، استاد را رونویسی می‌کند، دستورالعمل‌ها را استخراج می‌کند، و اقدامات را پیش از اجرا برای تایید شما نمایش می‌دهد.

اگر فقط می‌خواهید ربات در کلاس حاضر باشد، نسخهٔ پایه کافی است. اگر می‌خواهید ربات در زمان پرسیدن نام شما پاسخ بدهد یا دستورات استاد را اجرا کند، نسخهٔ کامل را بگیرید.

## پیش‌نیازها

> **Google Chrome باید روی سیستم نصب باشد.** درایور chromedriver مناسب داخل بستهٔ اجرایی قرار دارد — نیازی به نصب Python، Selenium یا chromedriver به‌صورت جداگانه ندارید.

- **ویندوز:** ویندوز ۱۰ یا جدیدتر (x86-64)
- **لینوکس:** هر توزیع مدرن x86-64 با `glibc` نسخهٔ ۲.۳۱ یا جدیدتر (اوبونتو ۲۰.۰۴+، فدورا ۳۲+، دبیان ۱۱+)

### پیش‌نیازهای اضافی نسخهٔ کامل

نسخهٔ کامل در اولین استفادهٔ حالت شنونده، مدل Whisper را دانلود می‌کند:

- **مدل Whisper large-v3**: ~۳ گیگابایت، از Hugging Face
- **کتابخانه‌های CUDA** (اختیاری، در صورت داشتن کارت گرافیک NVIDIA): ~۱ گیگابایت
- **Ollama** (اختیاری، برای استخراج محلی): نصب جداگانه

این دانلودها فقط یک‌بار انجام می‌شوند. از دفعهٔ بعد، همه‌چیز به‌صورت محلی و آفلاین کار می‌کند.

## نصب و اجرا

<details>
<summary><b>ویندوز — نسخهٔ پایه</b> (کلیک کنید)</summary>

1. فایل `SkyroomBot-*-windows-x64.exe` را دانلود کنید.
2. آن را در پوشه‌ای دلخواه قرار دهید (مثلاً `C:\Program Files\SkyroomBot\`).
3. روی آن دوبار کلیک کنید. اگر SmartScreen هشدار داد، روی **More info** و سپس **Run anyway** کلیک کنید. (برنامه امضای دیجیتال ندارد.)
4. در اولین اجرا از منوی **پرونده → بارگذاری فایل JSON…** فایل برنامهٔ هفتگی خود را انتخاب کنید.

تنظیمات شما در مسیر `%APPDATA%\SkyroomBot\` ذخیره می‌شود.

</details>

<details>
<summary><b>ویندوز — نسخهٔ کامل</b> (کلیک کنید)</summary>

1. فایل `SkyroomBot-*-windows-x64-full.zip` را دانلود کنید.
2. آن را در پوشه‌ای دلخواه استخراج کنید.
3. وارد پوشهٔ `SkyroomBot\` شوید و `SkyroomBot.exe` را اجرا کنید.
4. در اولین اجرا از منوی **پرونده → بارگذاری فایل JSON…** فایل برنامهٔ هفتگی خود را انتخاب کنید.
5. برای فعال‌سازی حالت زنده، در فایل JSON هر کلاس یک کلید `"live": true` اضافه کنید (به بخش «فعال‌سازی حالت زنده» مراجعه کنید).

</details>

<details>
<summary><b>لینوکس — نسخهٔ پایه</b> (کلیک کنید)</summary>

1. فایل `SkyroomBot-*-linux-x64` را دانلود کنید.
2. آن را قابل‌اجرا کنید:

   ```bash
   chmod +x SkyroomBot-*-linux-x64
   ```

3. آن را اجرا کنید:

   ```bash

   ```

4. در اولین اجرا از منوی **پرونده → بارگذاری فایل JSON…** فایل برنامهٔ هفتگی خود را انتخاب کنید.

تنظیمات شما در `~/.config/SkyroomBot/` ذخیره می‌شود.

</details>

<details>
<summary><b>لینوکس — نسخهٔ کامل</b> (کلیک کنید)</summary>

1. فایل `SkyroomBot-*-linux-x64-full.tar.gz` را دانلود کنید.
2. آن را استخراج کنید:

   ```bash
   tar -xzf SkyroomBot-*-linux-x64-full.tar.gz
   ```

3. وارد پوشه شوید و اجرا کنید:

   ```bash

   ./SkyroomBot
   ```

4. در اولین اجرا از منوی **پرونده → بارگذاری فایل JSON…** فایل برنامهٔ هفتگی خود را انتخاب کنید.
5. برای فعال‌سازی حالت زنده، در فایل JSON هر کلاس یک کلید `"live": true` اضافه کنید.

## فعال‌سازی حالت زنده (فقط نسخهٔ کامل)

حالت زنده در هر کلاس به‌صورت جداگانه فعال می‌شود. در فایل JSON برنامه، برای کاربر یک `field` و برای هر کلاسی که می‌خواهید شنونده فعال باشد، `"live": true` اضافه کنید:

```json
[
    {
        "user_name": "امیررضا اسفندیاری",
        "field": "Health Information Technology",
        "classes": [
            {
                "name": "کد گذاری مرگ و میر 2",
                "url": "https://vc8.ajums.ac.ir/ch/piraminicare",
                "day": "سه‌شنبه",
                "time": "10:00am",
                "end_time": "12:00pm",
                "live": true
            }
        ]
    }
]
```

کلاس‌هایی که `"live": true` ندارند، بدون شنونده اجرا می‌شوند.

---

## استفاده از حالت زنده

1. برنامه را اجرا کنید.
2. به تب **جارویس** بروید.
3. روی **تنظیمات** کلیک کنید و پیکربندی اولیه را انجام دهید (مدل، بک‌اند استخراج، دستگاه ضبط).
4. فایل JSON را بارگذاری کنید و روی **شروع** بزنید.
5. ربات وارد کلاس می‌شود و شنونده فعال می‌شود.

در طول کلاس:

- رونویسی زندهٔ صحبت استاد در تب جارویس نمایش داده می‌شود
- وقتی استاد شما را صدا می‌زند یا دستوری می‌دهد، یک تصمیم در ستون کناری ظاهر می‌شود
- با **Enter** تایید یا با **Esc** رد کنید

## حریم خصوصی

- تمام پردازش صوت به‌صورت محلی انجام می‌شود
- صدای خام کلاس هیچ‌گاه ذخیره نمی‌شود
- فقط رونویسی و تصمیمات در `~/.jarvis/logs/` ذخیره می‌شوند
- اگر بک‌اند استخراج روی `cloud` تنظیم شود، متن رونویسی به سرور 9Router محلی شما فرستاده می‌شود (نه به هیچ سرویس خارجی)

## معماری

```
┌─────────────────────────────────────────────────┐
│  pyqt.py — رابط کاربری (PyQt6, نخ اصلی)          │
│  تنظیمات، تقویم هفتگی، تب‌ها، صف تایید Jarvis    │
└──────┬──────────────────────────────┬───────────┘
       │ tasks                        │ callbacks (Qt signals)
       ▼                              │
┌─────────────────────────────────────────────────┐
│  skyroom_core.py — موتور (بدون وابستگی به UI)    │
│  یک نخ (thread) برای هر کلاس                     │
│    مرورگر ناشناس ← ورود میهمان ← ثبت نام         │
│    ارسال پیام حضور ← ماندن تا پایان              │
│    نگهبان WebSocket: قطع شد ← ورود مجدد کامل     │
└──────┬──────────────────────────────┬───────────┘
       │ work_queue                   │ acquire / release
       ▼                              ▼
┌──────────────────┐   ┌──────────────────────────┐
│  مرورگر Chrome   │   │  jarvis_integration.py   │
│  (Selenium)      │   │  پل بین ربات و Jarvis    │
└──────────────────┘   └────────────┬─────────────┘
                                    │ listener thread
                                    ▼
                         ┌──────────────────────────┐
                         │  Jarvis (پکیج جداگانه)     │
                         │  ضبط صدا ← Whisper        │
                         │  استخراج دستور ← صف تایید │
                         └──────────────────────────┘

wake_scheduler.py — اسکریپت مستقل: زمان بیداری بعدی را با
rtcwake (لینوکس) یا Task Scheduler (ویندوز) تنظیم می‌کند.
```

نکات طراحی:

- موتور (`skyroom_core.py`) هیچ وابستگی به PyQt ندارد — منطق زمان‌بندی، نخ‌ها و درایور مرورگر جدا از رابط کاربری است و به‌صورت مستقل با `unittest` تست می‌شود (`tests/`).
- هر کلاس در نخ خودش اجرا می‌شود؛ توقف (`stop_event`) و خروج از همهٔ نخ‌ها هماهنگ است.
- تصمیم‌های Jarvis هرگز مستقیم درایور را لمس نمی‌کنند: از طریق `queue.Queue` به نخ وظیفه سپرده می‌شوند، چون Selenium باید از همان نخی صدا زده شود که درایور را ساخته است.
- نگهبان اتصال با تزریق یک اسکریپت JS شمارنده‌های `WebSocket` صفحه را می‌خواند؛ سوکت‌هایی که هرگز `open` نشده‌اند شمرده نمی‌شوند تا ورود مجدد بیهوده رخ ندهد.
- بدون پکیج Jarvis، `jarvis_integration.py` به حالت افتاده (`JARVIS_AVAILABLE=False`) می‌رود: تب Jarvis ساخته نمی‌شود و کلاس‌ها بدون شنونده اجرا می‌شوند. همین رفتار، تفکیک نسخهٔ پایه و کامل را ممکن می‌کند — کد یکی است، فقط باندل متفاوت است.
